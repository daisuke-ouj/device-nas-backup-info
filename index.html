Device NAS Drive Backup

Personal backup utility

Privacy policy

Purpose

Device NAS Drive Backup is a personal utility for copying the account owner's Google Drive files to storage controlled by that owner. It uses rclone on the owner's computer. It is not a public file-storage or account-registration service.

Google Drive access

The utility requests only https://www.googleapis.com/auth/drive.readonly. It reads file contents and metadata to create and check backups. It does not upload, edit, rename, share or delete files in Google Drive.

Owner-controlled backups

Backup data is stored on the owner's NAS. Previous file versions may be kept for recovery. The owner controls backup retention and deletion on their own storage.

This informational website does not provide login, file upload or backup execution. Backed-up files are not sent to this website.

Support

This utility is for the owner's personal use. Contact information for the owner is provided on Google's OAuth consent screen.

See the privacy policy for information about permissions, storage, retention and revoking access.
