# Device NAS Drive Backup — public information

This repository contains only the public application information and privacy policy for a personal Google Drive backup utility.

- [Application information](https://daisuke-ouj.github.io/device-nas-backup-info/)
- [Privacy policy](https://daisuke-ouj.github.io/device-nas-backup-info/privacy.html)

The website does not run backups or accept logins or uploads. Backup software, credentials, configuration, logs and private data are not stored here.

GitHub Pages publishes the static HTML files from the root of the `main` branch. No build dependencies are required.
