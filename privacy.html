Device NAS Drive Backup — personal backup utility

Purpose

Device NAS Drive Backup copies the account owner's Google Drive files to storage controlled by that owner, using rclone on the owner's computer. It is not a public file-storage or account-registration service.

Google data and permissions

The utility requests only https://www.googleapis.com/auth/drive.readonly. It reads file contents and metadata to create and check backups. It does not upload, edit, rename, share or delete files in Google Drive.

Storage and use

Backup data is stored on the owner's NAS. Previous file versions may be kept for recovery. OAuth credentials are stored locally, outside the source-code repository, with operating-system access restrictions.

The utility does not send backed-up files to this website or use them for advertising or AI training.

Retention and control

The owner controls backup retention and deletion on their own storage. Access can be revoked in the Google Account's third-party connections settings. Revoking access stops future Google Drive reads but does not erase existing local or NAS backup copies.

Support

This is for the owner's personal use. Contact information for the owner is provided on Google's OAuth consent screen. This page contains no credentials, private file names, network addresses or backup data.

Website

This informational page does not provide login, file upload or backup execution. It is hosted with GitHub Pages; its host may process normal web requests under GitHub's privacy statement.
